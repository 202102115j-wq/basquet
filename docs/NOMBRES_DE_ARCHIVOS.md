# Nombres de archivos

Los archivos creados específicamente para la práctica usan nombres en español, por ejemplo:

- `ControladorAutenticacion.php`
- `ControladorEquipo.php`
- `ControladorJugador.php`
- `ControladorPartido.php`
- `ControladorEstadistica.php`
- `Usuario.php`, `Equipo.php`, `Jugador.php`, `Partido.php`
- `inicio_sesion.blade.php`, `registro.blade.php`, `crear.blade.php`, `editar.blade.php`, `listado.blade.php`
- `crear_base_datos.sql`
- `configurar_laragon.bat`

Se conservan los nombres estándar que Laravel o las herramientas esperan, como `composer.json`, `artisan`, `.env.example`, `routes/web.php`, `config/app.php`, `DatabaseSeeder.php`, `phpunit.xml` y `TestCase.php`. Renombrarlos rompería convenciones o carga automática del framework.
