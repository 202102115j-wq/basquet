# Liga de Basquetbol — Parte 1 de 8

Aplicacion web para administrar una liga de basquetbol con Laravel 12 y Laragon.

**Modulo:** Estructura de Laravel y registro, inicio y cierre de sesión, panel protegido.

Para instalar o actualizar el proyecto en Windows, lee [LEEME_LARAGON.md](LEEME_LARAGON.md).

El repositorio incluye **pruebas continuas** con GitHub Actions, disponibles en la pestana *Actions* tras cada `git push`. Estas pruebas ejecutan Composer, las rutas Laravel y PHPUnit en GitHub.

Mantener `.git` y `.env` originales al avanzar de una etapa a otra.
